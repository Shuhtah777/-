# Практика: автомат станів

## Місія

Місія робота — рухатися вперед, знайти перешкоду, об'їхати її та повернутися назад.

Для реалізації місії використано 4 стани:

1. **Пошук** — робот їде вперед та вимірює відстань до перешкоди ультразвуковим датчиком.
2. **Об'їзд** — після виявлення перешкоди робот повертає праворуч та проїжджає вперед.
3. **Повернення** — робот розвертається та їде назад.
4. **Завершення** — робот зупиняється.

## Переходи між станами

 **Пошук → Об'їзд** — якщо ультразвуковий датчик показує менше 15 см.
 **Об'їзд → Повернення** — після завершення об'їзду через 3 секунди.
 **Повернення → Завершення** — після руху назад протягом 3 секунд.

## Результат виконання

Під час виконання програми ультразвуковий датчик показував зменшення відстані:

`43.2 см → 41.6 см → ... → 15.9 см → 13.8 см`

При значенні `13.8 см` робот виявив перешкоду та виконав перехід:

`ПОШУК → ОБ'ЇЗД`

Після об'їзду робот перейшов до стану повернення, розвернувся та проїхав назад. Після завершення руху робот перейшов у стан завершення та зупинився.
